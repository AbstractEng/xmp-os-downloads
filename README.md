# XMP OS installer previews

[Download the installer previews](https://github.com/AbstractEng/xmp-os-downloads/releases/tag/installer-preview-2026-11-18) · [Hardware setup guide and videos](https://irregularsizes.com/xmpos/manual/#hardware-setup)

For **MPC Live Mk1 / ACV8 running official MPC OS 3.10.1**. Obtain Akai's matching official Gen 1 updater separately; the installer prepares the USB system and recovery files locally.

| Download | Preview scope |
| --- | --- |
| macOS | Intel x64; ad-hoc signed, not Developer ID notarized. Apple Silicon is not qualified. |
| Windows | x64, unsigned preview. Physical USB driver/flash qualification remains pending. |

Each ZIP includes component notices, corresponding source and rebuild/relink instructions. Akai firmware, extracted stock rootfs, owner-generated USB images, credentials and unit verification profiles are not included. SHA-256 checksums accompany each release.

Extract the complete ZIP before opening the installer. On Windows, keep the resources folder beside XMP OS Installer.exe. Follow the manual's supported firmware, power, confirmation and stock-recovery steps.

This repository hosts installer downloads. Existing project repositories have not been made public.
